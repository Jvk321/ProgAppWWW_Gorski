Uruchomienie:
- Otwórz folder projektu w Visual Studio Code.
- Otwórz plik index.html w przeglądarce lub użyj rozszerzenia Live Server.

Źródła grafik:
- grafika wygenerowana przez AI.

Przepływ działania JavaScript

Zdarzenie: 
- użytkownik zmienia produkt, ilość lub wysyła formularz.
Dane wejściowe: 
- JavaScript pobiera wybrany produkt, ilość i wiadomość.
Obliczenie: 
- sprawdza poprawność danych i oblicza cenę w groszach, a następnie przelicza ją na złote.
Zmiana DOM:
- aktualizuje cenę, komunikaty błędów i podsumowanie za pomocą textContent oraz hidden, bez przeładowania strony.
